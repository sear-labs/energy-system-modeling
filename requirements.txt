# What this repository tolerates. Ranges with UPPER BOUNDS, per Part 1 rule 3:
# an unpinned dependency will one day install a major version with a changed API
# and either break or -- worse -- silently alter results.
#
# This file is half the claim. `requirements-lock.txt` is the other half: the
# resolved list that actually produced the outputs committed in the notebooks.
# A range says what will install; only the lock says what ran.
#
#   python -m venv <short-path>/esm      # SHORT: Windows long-path limits bite
#   <short-path>/esm/Scripts/pip install -r requirements.txt
#   <short-path>/esm/Scripts/python -m ipykernel install --user --name esm \
#       --display-name "Python (esm: pypsa)"
#
# Interpreter: Python 3.13.9 on win32 is what produced the committed outputs.
